Pi side: 

sudo apt-get update
sudo apt-get upgrade
sudo apt-get install python-pip
sudo apt-get install python-dev
sudo pip install future
sudo apt-get install screen wxgtk libxml libxslt
sudo pip install pyserial 
sudo pip install dronekit
sudo pip install MAXProxy

Use command sudo raspi-config and do the following:
At the interface options, login shell access over serial should be disabled. 
Serial port hardware should be enabled.

Bluetooth must be disabled:
sudo nano /boot/config.txt.
Once inside config file these must be done:

At the bottom you must have these lines: 
enable_uart=1
dtoverlay=disable-bt

Then reboot.

After rebooting enter these:
sudo pip install PyYAML mavproxy

Then run:

sudo mavproxy.py --master=/dev/ttyAMA0

You should be seeing the command line interface of PixHawk. Like below.

STABILIZE>

To change the mode enter:
mode GUIDED

To test you may enter this command: (It will run the motors, be careful)
arm throttle



PixHawk side:
ASE team already configured the pixhawk using Mission Planner. So the latest firmaware is installed. It seems nothing has to be done in our part. Which pin should go where can be found in the pictures. I found different variations on this. Since we have external power source, we won't be needing 5V pin.
